# Pirikara Homebrew tap

Install [Ravel](https://github.com/Pirikara/Ravel), a CLI that generates SBOMs from project dependencies, installed systems, and container images:

```sh
brew install pirikara/tap/ravel
ravel version
```

The formula downloads the platform-specific binary from the GitHub Release and verifies its SHA-256 checksum. See the [Ravel install guide](https://github.com/Pirikara/Ravel/blob/main/docs/install.md) for other platforms and installation methods.
